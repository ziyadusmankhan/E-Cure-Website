# E-Cure brand assets

The client supplied `ecure-original.jpg` (688 × 1532px JPEG). It is retained unchanged.

`ecure-logo.webp` arranges separate crops of its actual house/cross/leaf artwork
and original wordmark into a horizontal lockup on black. `ecure-mark.webp` is a
square crop of the original mark. No artwork was redrawn, recolored, generated,
or subjected to background removal. These assets are for E-Cure branding only.

The horizontal derivative is 540 × 148px. Display with its intrinsic aspect ratio
on a black surface. The brand component continues to support custom CMS logos
and the original fallback for other business profiles.

`ecure-icon.png` is a 64px PNG derivative of the same supplied mark for browser
tabs. The app metadata icon selects it only for the E-Cure presentation; other
profiles retain the original platform artwork in `public/images/platform-icon.png`.
